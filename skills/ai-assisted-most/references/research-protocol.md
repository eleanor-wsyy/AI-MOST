# AI-assisted MOST reference

The workbench implements four separable procedures: LS15 structural scoring, one simulated participant (Pretending), a population forecast (Predicting), and optional repeated simulated participants. The first three use the same pair but must not share hidden results. The workbench stores completed calls in browser localStorage and exports JSON/CSV for later analysis.

The professor's question what if GPT? should be answered by repeating the same fixed image pairs and wording with the GPT-compatible provider, then comparing GPT and Gemini at the condition level. Keep provider, model, temperature, wording, image order, and valid-call count in the exported record.
